Technology Stack

Backend:
  • Flask 2.3.3 - Lightweight REST API
  • Python 3.8+ - Core logic
  • Gunicorn - Production server
Frontend:
  • HTML5/CSS3 - Responsive design
  • Vanilla JavaScript ES6+ - Dynamic UI
  • Chart.js - Data visualization
AI & Integrations:
  • Groq Cloud - LLaMA 3.3 70B LLM
